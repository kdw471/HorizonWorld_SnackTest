## 1. 데모 범위 확정

원안 5-2가 정의한 "1 캐릭터, 1~2 몬스터 유형, 1 성장 스킬, 게임 플로우 시스템"을
그대로 지킨다. 아래 표의 **포함**만 만들고 나머지는 손대지 않는다.

| 영역 | 포함 | 제외 |
| --- | --- | --- |
| 캐릭터 | Mage 1종 | 검사 등 타 직업 |
| 스킬 | Fireball 1종 (Rule 3개 전부) | 나머지 8종 |
| 융합 | 없음 | Flame Lance는 M4에서 |
| 몬스터 | Chaser, Ranged | Swarm, Brute, Elite, Boss |
| 성장 | 레벨업 카드, 스택→Tier, 퀘스트 완료 연출 | 메타 프로그레션, 드롭·상자 |
| 루프 | 시작 → 10분 생존 → 사망 → 정산 표시 | 보스, 클리어, 저장 |
| 아트 | 무료 에셋 + 기본 이펙트 | 자체 제작 에셋 |

**데모의 검증 질문은 하나다**: *"스킬을 쓰다 보니 스킬이 자라고, 자란 스킬이 다시
쓰고 싶어지는가?"* 이 질문에 답이 안 나오면 다른 어떤 콘텐츠를 붙여도 소용없다.

## 2. 마일스톤

원안의 Phase 계획을 현재 진척(26/03 기준)에 맞춰 재배열했다.

| M | 이름 | 내용 | 기간 |
| --- | --- | --- | --- |
| M0 | 기반 (완료분 포함) | GAS 모듈, AttributeSet 3종, 이동·카메라, 스킬 GA 테스트, Projectile 이펙트 | 진행 중 |
| M1 | 전투 성립 | Chaser 몬스터, 데미지 Execution, 플로팅 텍스트, 사망 로직, 허수아비 더미 | 1~2주 |
| M2 | 성장 성립 | 태그 스택 컨테이너, 스택 소스 처리, Tier 판정, Rule 3종, 완료 연출 | 2~3주 |
| M3 | 루프 성립 | 경험치·레벨업, 카드 3장 선택 UI, 스폰 디렉터, 10분 생존 플로우, 정산 | 2~3주 |
| M4 | 확장 | 스킬 9종, Ranged·Swarm, 융합 1종, Tier별 이펙트 | 4주 |
| M5 | 폴리싱 | 메타 프로그레션, 보스, 사운드·UI 폴리싱, 밸런싱 | 3주 |

- M1~M3이 데모의 전부다. **M3 종료 시점에 재미 검증을 하고, 여기서 판단이 서지 않으면
  M4로 넘어가지 않는다.**
- 26/03/04의 미완료 TODO 4건(테스트 몬스터, 플로팅 텍스트, 데미지+GE+AbilitySet 연동,
  사망 로직)이 곧 M1의 작업 목록이다.

1. `APH_EnemyCharacter` + ASC 직접 소유 구조
2. `UPH_EnemyDataAsset` + Chaser 정의

5. `IncomingDamage` 메타 어트리뷰트 처리
