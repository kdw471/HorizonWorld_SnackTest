# 03. 전투와 데미지 시스템

> 상위 문서: `ReadMe.md`
> 형제 문서: `04_스킬_시스템_Stack과_Rule.md`, `08_몬스터와_스폰_디렉터.md`

## 1. 원칙

- **데미지 타입은 하나**다(원안 3-3). 원소(화/빙/풍)는 데미지 타입이 아니라 **Rule과
  디버프의 출처**로만 기능한다. 상성표는 만들지 않는다.
- 방어는 **절대 감소(Armor) + 퍼센트 감소(Resistance)를 병용**한다. 원안은 둘 중
  하나로 열려 있었으나, 몬스터 스케일링과 후반 데미지 인플레이션을 동시에 다루려면
  두 축이 모두 필요하다. [확정 제안]
- 모든 데미지는 GameplayEffect의 Execution Calculation 한 곳을 통과한다. 우회 경로를
  만들지 않는다.

## 2. Attribute 구성

원안 26/02/20의 3분할(Status / Combat / Skill)을 유지한다.

### 2-1. `UPH_StatusAttributeSet`

`Health`, `MaxHealth`, `HealthRegen`, `Mana`, `MaxMana`, `ManaRegen`, `MoveSpeed`

### 2-2. `UPH_CombatAttributeSet`

`AttackPower`, `CritChance`, `CritDamage`, `CooldownReduction`, `AreaScale`,
`ProjectileSpeed`, `DurationScale`, `Armor`, `Resistance`, `PickupRadius`

### 2-3. `UPH_SkillMetaAttributeSet`

`SkillPoints`, `TotalKillCount`, `TotalHitCount` 등 **전역 메타 수치만** 담는다.
스킬별 사용 횟수·스택은 Attribute가 아니라 **태그 스택 컨테이너**로 관리한다.
스킬 수만큼 Attribute를 늘리면 확장이 불가능하기 때문이다. → `04`, `11`

### 2-4. Meta Attribute

`IncomingDamage`(전용 메타). Execution이 여기에 값을 쓰고, `PostGameplayEffectExecute`
에서 Health로 반영한다.

## 3. 데미지 계산식 [제안]

```
Raw        = SkillBaseDamage
             * (1 + 0.10 * SkillLevel)          // 스킬 레벨(카드 강화)
             * RuleMultiplier                    // Rule 곱연산 누적, 04 참고
             * (1 + AttackPower / 100)           // 캐릭터 공격력

Crit       = IsCrit ? (CritDamage / 100) : 1.0   // IsCrit = Random < CritChance
Mitigated  = (Raw * Crit - Target.Armor) * (1 - Target.Resistance / 100)
Final      = Max(Mitigated, Raw * 0.05)          // 최소 보장 5%
```

- 곱연산 순서를 고정한다: **스킬 자체 → Rule → 캐릭터 → 치명타 → 방어**.
- `Resistance` 상한 75%, `Armor`는 상한 없음(대신 최소 보장 5%가 하한을 만든다).
- 몬스터가 플레이어를 때릴 때도 같은 식을 사용한다.

### 3-1. 다단히트와 DoT

| 구분 | 처리 |
| --- | --- |
| Multi Hit | 히트마다 위 계산식을 독립 수행. 각 히트가 스택 소스가 된다 |
| DoT(화상 등) | 주기 GE(Period 0.5초). 적용 시점의 계산 결과를 스냅샷하여 틱마다 사용 |
| 중첩 | DoT는 스택 3까지 중첩, 갱신 시 지속시간 리셋 |

## 4. 상태 이상(Debuff)

원안 26/02/23에서 스택 소스로 지목한 요소들이다. 디버프는 **Rule을 통해서만** 얻는다.

| 디버프 | 태그 | 효과 [제안] | 지속 |
| --- | --- | --- | --- |
| 화상 | `Debuff.Burn` | 초당 공격력의 15% 데미지, 3스택 | 3초 |
| 둔화 | `Debuff.Chill` | MoveSpeed -30% | 2초 |
| 감전 | `Debuff.Shock` | 받는 데미지 +10%, 3스택 | 4초 |
| 취약 | `Debuff.Sunder` | Armor -50% | 3초 |
| 속박 | `Debuff.Root` | 이동 불가 | 1초 |

- 몬스터가 플레이어에게 거는 디버프는 데모 범위 밖으로 둔다.
- 디버프 적용 성공은 스택 +1의 소스다. → `04`
