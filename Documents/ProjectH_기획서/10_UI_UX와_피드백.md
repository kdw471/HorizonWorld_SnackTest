# 10. UI/UX와 피드백 연출

> 상위 문서: `ReadMe.md` / 원안: `../Ideation/프로젝트_컨셉안.md` 3-4장, 4장
> 형제 문서: `05_퀘스트_숙달도_시스템.md`, `07_레벨업과_카드_선택.md`

원안이 히오스에서 명시적으로 지목한 재미 요소는 **"퀘스트를 달성할 때마다 피드백되는
사운드(띠링)와 캐릭터 팝업 UI"** 다. 이 문서는 그것을 사양으로 고정하기 위한 것이며,
우선순위상 다른 폴리싱보다 앞선다.

## 1. HUD 구성

```
┌──────────────────────────────────────────────┐
│ [경과 시간 12:34]        [처치 428]           │  상단 중앙
│                                              │
│                                              │
│                  (게임 화면)                  │
│                                       ┌────┐ │
│                                       │퀘스트│ │  우측: 진행 중 퀘스트 3개
│                                       │진행바│ │
│                                       └────┘ │
│ [체력바]                                      │  좌하단
│ [마나바]                                      │
│ [스킬 아이콘 6칸 + 각 스킬 스택 게이지]         │  하단 중앙
│ ▓▓▓▓▓▓▓▓░░░░░░ Lv.14                         │  최하단: 경험치
└──────────────────────────────────────────────┘
```

- **스킬 아이콘마다 스택 게이지를 붙인다.** 다음 Tier까지 얼마나 남았는지 항상 보여야
  성장이 체감된다. 이것이 이 게임의 HUD에서 가장 중요한 요소다.
- 퀘스트 패널은 3개까지만 표시하고, 완료 임박(80% 이상) 항목을 위로 정렬한다.

## 2. 퀘스트 완료 연출 [제안 — 원안의 핵심 요구]

완료 순간 0.1초 안에 아래가 동시에 발생해야 한다.

| 채널 | 연출 | 타이밍 |
| --- | --- | --- |
| 사운드 | "띠링" 상승 2음 아르페지오. 다른 SFX보다 6dB 크게, 전용 믹서 버스 | 0.00s |
| 화면 | 화면 가장자리 골드 비네트 플래시 | 0.00 ~ 0.25s |
| 캐릭터 | 캐릭터 발밑 링 파티클 상승 | 0.00 ~ 0.6s |
| 팝업 UI | 캐릭터 머리 위에 스킬 아이콘 + "MASTERED" 텍스트 카드가 스케일 인 | 0.05 ~ 2.5s |
| 시간 | Rule 선택이 필요한 경우에만 0.2초 뒤 시간 정지 | 0.20s |

- 팝업은 **캐릭터에 붙어서 뜬다.** 화면 구석 토스트가 아니다. 원안이 지목한 것은
  "캐릭터의 팝업 UI"이며, 시선이 캐릭터에 있는 게임에서 이는 중요한 차이다.
- 연출이 겹칠 때는 큐에 넣어 0.3초 간격으로 순차 재생한다.

## 3. 레벨업 카드 UI

- 시간 정지 후 배경을 40% 어둡게, 카드 3장을 화면 중앙에 가로 배치.
- 카드 등장은 0.15초 간격 순차 슬라이드 인. 마우스 호버 시 8도 기울기 + 스케일 1.05.
- 키보드 1/2/3으로도 선택 가능하게 한다(마우스 이동 시간을 아낀다).
- 융합 카드는 다른 카드보다 크게 표시하고 전용 프레임·사운드를 쓴다.

## 4. 이펙트 성장 규격

원안 26/03/03의 "점진적으로 화려해지는 이펙트"를 Tier에 연동한다.

| Tier | 이펙트 규격 |
| --- | --- |
| T0 | 단색 코어 + 짧은 트레일. 가장 단순 |
| T1 | 트레일 길이 1.5배, 스파크 추가 |
| T2 | 코어에 회전 링, 착탄 시 소형 폭발 |
| T3 | **형태 변화.** 메쉬 교체 + 지속 파티클 + 지면 데칼 |
| T4 | 발광 강도 상승, 시전 시 캐릭터에 원소 오라 |

- 나이아가라 시스템은 **하나로 만들고 `Tier` 파라미터로 분기**한다. Tier마다 별도
  에셋을 만들면 스킬 9종 × 5단계 = 45개가 되어 관리가 불가능하다.
- 원안 4장의 아트 방향("심플한 아트풍에 심플하지 않은 이펙트")은 곧 **캐릭터·환경은
  저채도 단순, 스킬 이펙트만 고채도 고대비**로 해석한다. 화면이 가득 차는 후반에도
  적과 이펙트가 구분되어야 한다.

## 5. 가독성 규칙 (뱀서류 필수)

- 적 실루엣은 항상 이펙트 위에 보이도록 렌더 우선순위를 조정한다.
- 플레이어 캐릭터에는 상시 미세한 아웃라인을 넣는다.
- 자신이 받는 데미지는 화면 방향 지시자(피격 방향 붉은 호)로 표시한다.
- 이펙트 밀도가 임계치를 넘으면 자동으로 파티클 스케일을 낮춘다(가독성 우선).
