# 13. 미결 이슈와 결정 대기 사항

> 상위 문서: `ReadMe.md`
> 형제 문서: `12_개발_마일스톤과_데모_범위.md`

본 기획서에서 [제안]·[보류]로 표기한 항목 중, **결정이 늦어지면 작업이 막히는 것**을
우선순위 순으로 정리했다.

## 1. 지금 결정해야 하는 것 (M1~M2를 막는다)

| # | 이슈 | 선택지 | 기획서의 제안 |
| --- | --- | --- | --- |
| 1 | 런 사이클 정책 | 이어하기(RPG형) / 매판 리셋(뱀서형) | **매판 리셋 + 메타 층 분리** (`09` 2장) |
| 2 | 퀘스트 수명 | 런 한정 / 영구 | **런 한정, 해금만 영구** (`05` 4장) |
| 3 | 스택 보너스 상한 | 상한 없음 / 60% 상한 | **60% 상한 후 Rule로 전환** (`04` 3-2) |
| 4 | 방어 방식 | 절대 감소 / 퍼센트 / 병용 | **병용** (`03` 1장) |
| 5 | 스킬별 진행도 저장 방식 | Attribute / 태그 스택 | **태그 스택** (`05` 5-1) |

1·2번은 서로 얽혀 있다. 1번을 "이어하기"로 뒤집으면 `05`, `07`, `09`를 다시 써야 하므로
**M2 착수 전에 확정**해야 한다.

## 2. M3까지 미뤄도 되는 것

| # | 이슈 | 내용 |
| --- | --- | --- |
| 6 | 마우스 조준 채택 범위 | 전 스킬 마우스 조준 vs 일부 자동 타게팅. `04` 6장은 스킬별 속성으로 제안 |
| 7 | 레벨업 카드 장수 | 3장 고정 vs 4장(메타 해금). `07`은 3장 + 메타 해금 제안 |

| 10 | 세션 목표 시간 | 15~25분 제안. 실제 플레이 후 조정 |

## 3. M4 이후로 미룬 것 [보류]

- 스킬 획득 경로 확장: 몬스터 드롭(D~A, 극소 확률 S), 보물 상자(B·A 중심)
- 아이템·인벤토리·재화(런 내) 시스템 — 원안 3-3에 있으나 데모에서 제외
- 회피(대시) 조작
- 2차 융합(융합 스킬끼리의 재융합)
- 런 시작 시 변형 룰(주문서) 선택
- 무한 모드
- 검사 등 추가 직업 — 원안 26/02/23의 "쾌도, 중도" 방향성
- 멀티플레이 실제 검증 (구조만 유지, `11` 7장)

## 4. 원자료에서 답을 얻지 못한 항목

- **아트 컨셉의 구체적 레퍼런스**: 원안 4장은 "감이 오지 않는다"로 열려 있다.
  본 기획서는 "저채도 단순 캐릭터/환경 + 고채도 고대비 이펙트"(`10` 4장)로만 제안했다.
  실제 레퍼런스 수집이 필요하다.
- **노션 "프로젝트" 섹션의 링크 페이지들**: 공개 공유 대상이 아니어서 내용을 확인하지
  못했다. 여기에 이미 결정된 사항이 있다면 본 기획서와 대조가 필요하다.
- **08/26 「스킬 시스템1」 문서**: 제목만 있고 본문이 비어 있다.
