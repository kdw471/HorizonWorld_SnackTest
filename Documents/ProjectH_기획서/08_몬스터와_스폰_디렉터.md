## 1. 몬스터 공통 사양

원안 3-2의 4개 항목을 그대로 사양화한다.

| 항목 | 내용 |
| --- | --- |
| 이동·회전 | 플레이어 위치를 추적. NavMesh 사용, 회피는 RVO |
| 기본 공격 | 자동 공격. 공격 범위 안에 플레이어 감지 시 발동 |
| 스킬 시전 | 자동 시전. 감지 범위 안에서 쿨타임마다 발동 |
| 강화 | **플레이어 레벨**에 따라 종류와 스펙이 강화 |

- 몬스터도 ASC를 갖는다. 단 PlayerState가 없으므로 **Character가 직접 ASC를 소유**한다
  (플레이어와 다른 구조). → `11`
- 몬스터 AI는 상태 기계 3상태로 충분하다: `Idle → Chase → Attack`. 비헤이비어 트리는
  데모에서 사용하지 않는다. [제안]

## 3. 스펙 스케일링 [제안]

```
HP      = BaseHP * (1 + 0.14 * PlayerLevel)
Damage  = BaseDamage * (1 + 0.08 * PlayerLevel)
Armor   = floor(PlayerLevel * 0.5)
ExpGem  = BaseGem (스케일링 없음)
```

- 이동 속도는 스케일링하지 않는다. 이동 속도가 오르면 회피 자체가 불가능해진다.
- Armor를 함께 올리는 이유는, 플레이어의 다단히트 계열 스킬이 무한히 유리해지는 것을
  막기 위해서다. → `03` 3장의 최소 보장 5%와 함께 작동한다.

## 4. 스폰 디렉터

### 4-1. 예산(Budget) 방식 [제안]

시간당 스폰 예산을 정하고, 유형별 비용만큼 소모하며 스폰한다.

```
Budget(t) = 20 + 6 * floor(t / 60)     // t = 경과 초
비용: Chaser 1, Ranged 2, Swarm 0.5, Brute 6, Elite 30
```

- 예산은 매 초 갱신되고, 화면 위 동시 존재 상한은 **150체**로 고정한다(성능 상한).
- 상한에 걸리면 가장 먼 몬스터부터 디스폰하고 예산을 회수한다.

### 4-2. 스폰 위치

- 카메라 뷰포트 바깥 **200~400 유닛** 링 영역에서 무작위 스폰.
- 플레이어 이동 방향 전방 쪽에 60% 가중치를 준다. 뒤에서만 나오면 도망만 치게 된다.

## 5. 데미지 테스터

08/24에 요구된 "간단한 데미징 테스터(허수아비)"를 개발 도구로 사양화한다.

- 무한 체력, 이동/공격 없음, 받은 데미지의 **DPS·총합·히트 수**를 머리 위에 표시.
- 콘솔 명령 `PH.SpawnDummy [개수]`로 스폰. 스킬 밸런싱의 기준 계측기로 사용한다.
