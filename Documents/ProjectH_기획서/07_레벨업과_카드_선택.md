# 07. 레벨업과 카드 선택

> 상위 문서: `ReadMe.md` / 원안: `../Ideation/GAS_구현_로드맵.md` Phase 2
> 형제 문서: `04_스킬_시스템_Stack과_Rule.md`, `06_스킬_융합_시스템.md`

## 1. 경험치

- 몬스터 처치 시 경험치 젬을 드롭한다. 젬은 `PickupRadius` 안으로 들어오면 플레이어를
  향해 가속 이동하여 흡수된다.
- 젬 가치: 일반 1, 강화형 3, 엘리트 25, 보스 200. [제안]

### 1-1. 레벨업 요구 경험치 [제안]

```
RequiredExp(n) = 5 + 8 * (n - 1) + 0.35 * (n - 1)^2
```

| 레벨 | 필요 경험치 | 누적 |
| --- | --- | --- |
| 2 | 5 | 5 |
| 5 | 32 | 66 |
| 10 | 105 | 517 |
| 20 | 265 | 2,432 |
| 30 | 500 | 6,150 |

- 목표: 도입 구간(0~2분)에 3레벨, 확장 구간(2~8분)에 12레벨 부근, 20분 시점 25~30레벨.
- 레벨업 순간 **시간을 정지**시키고 카드 UI를 띄운다(뱀서류 관례).

## 2. 카드 종류

| 종류 | 내용 | 기본 가중치 |
| --- | --- | --- |
| 신규 스킬 | 미보유 스킬 획득 | 100 |
| 스킬 강화 | 보유 스킬 Level +1 (최대 5) | 80 |
| 캐릭터 강화 | Attribute 상승(체력, 이속, 쿨감 등) | 60 |
| 융합 | 조건 충족 시에만 등장 | 300 |
| 회복 | 체력 40% 회복 (즉시 소모) | 30, 체력 50% 이하일 때만 |

## 3. 카드 추출 규칙

원안 Phase 2의 "미보유 스킬을 무작위 3~4개 추출, 마스터한 스킬의 강화 카드는 가중치
조절"을 구체화한다.

1. 후보 풀에서 **가중치 기반 비복원 추출**로 3장을 뽑는다(4장은 메타 강화로 해금).
2. 보유 스킬이 **6개(상한)** 에 도달하면 신규 스킬 카드는 풀에서 제외한다.
3. Level 5에 도달한 스킬의 강화 카드는 풀에서 제외한다.
4. **마스터(T4) 한 스킬의 강화 카드는 가중치를 0.3배로 낮춘다.** 이미 성장이 포화된
   스킬에 카드를 더 쓰게 만들 이유가 없다.
5. Tier가 낮은(T0~T1) 보유 스킬의 강화 카드는 가중치 1.5배 — 방치된 스킬을 끌어올린다.
6. 같은 카드가 한 화면에 2장 나오지 않는다.
7. 3장 모두 뽑을 수 없는 극단적 상황에서는 회복 카드로 채운다.

## 4. 리롤

- 런당 기본 리롤 1회. 메타 강화로 최대 3회까지 확장. [제안]
- 리롤은 3장 전체를 다시 뽑는다. 개별 잠금은 두지 않는다(선택 시간이 길어진다).

## 5. 카드 UI 요구 사항

상세 레이아웃은 `10`을 참고한다. 여기서는 데이터 요구 사항만 정의한다.

각 카드는 다음 정보를 표시한다.

- 아이콘, 스킬/강화 이름, 등급(색상 테두리)
- 한 줄 설명 (효과 수치 포함)
- **현재 → 변경 후** 비교 문구 (강화 카드일 때)
- 소모되는 스킬 명시 (융합 카드일 때)

## 6. 데이터 정의

`UPH_SkillCardDataAsset` — 원안 Phase 2에서 정의한 데이터 에셋. 필드는 `11` 참고.

- 카드는 **전부 데이터 에셋**이다. 신규 스킬 추가가 코드 수정 없이 가능해야 한다.
- 카드 풀은 레벨 구간별 화이트리스트를 가질 수 있다(초반에 나오면 곤란한 카드 제외용).
