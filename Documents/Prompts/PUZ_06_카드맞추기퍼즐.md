## 프롬프트

**너의 역할:** 아래 명세를 그대로 만족하는 "카드 맞추기(메모리 매치)" 퍼즐을 구현하라. 카드 대신 **포탈 타일**을 사용하고, **폭탄 타일이 셔플 기믹**으로 작동하는 것이 이 퍼즐의 핵심 변형이다.

### 1. 컨셉 & 규칙 요약

- 뒷면으로 덮인 카드를 한 장씩 뒤집으며 짝을 맞추는 클래식 메모리 퍼즐과 **동일한 규칙**을 사용한다.
- **카드는 [포탈 타일]이 대신**하며, 포탈 타일을 활성화하면 나오는 **[오브젝트]를 모두 맞추는 것**이 플레이어의 목표다.
- 포탈 타일 중에는 **[폭탄]** 이 있다. 폭탄을 발견하면 **포탈 타일에 배치된 오브젝트의 위치가 랜덤으로 변경**된다.
- **카드 맞추기 퍼즐 중에는 리셋을 할 수 없다.** (폭탄이 리셋의 역할을 대신하기 때문) → **리셋 버튼을 눌러도 상호작용되지 않는다.**

### 2. 승패 조건

- **클리어:** 폭탄 외 **모든 오브젝트의 짝을 맞추어 레벨에서 제거**하면 클리어.
  - 폭탄을 포함한 타일을 제외한 모든 타일이 완료 상태가 되면 클리어.
  - **마지막에 남은 타일이 폭탄이라면 게임 클리어.**
- **실패:** 제한 시간 내 오브젝트의 짝을 맞추지 못하면 실패.

### 3. 기본 시스템 (게임 플로우)

```
1. 포탈 타일이 표시됨
2. 포탈을 활성화하면 오브젝트 또는 폭탄이 등장함
3. 폭탄일 경우 → 포탈 타일이 비활성화되고 오브젝트들의 위치가 랜덤으로 변경됨
4. 포탈 타일은 한 번에 최대 2개까지 활성화 가능함
5. 두 번째 포탈을 활성화하면 결과를 결정함
     - 첫 번째와 "같은" 오브젝트일 경우  → 포탈 타일이 [완료] 상태로 변함
     - 첫 번째와 "다른" 오브젝트일 경우  → 포탈 타일이 [기본] 상태로 돌아감
     - 폭탄일 경우                       → 3번과 동일
6. 남은 오브젝트를 확인함
     - 폭탄 타일을 제외한 모든 타일을 완료 상태로 만들면 게임 클리어
     - 남은 오브젝트가 있으면 다시 포탈 타일을 표시함
```

### 4. 예외 처리 (필수 구현)

```
- 하나의 포탈 타일을 활성화하는 "중"에 두 번째 포탈을 활성화하는 것도 가능함.
- 단, 포탈에서 활성화된 오브젝트가 "폭탄"인 경우에는 플레이어의 조작이 불가함.
- 포탈을 "동시에" 활성화하는 것은 불가능함.
- 한 번 상호작용한 타일을 다시 상호작용하는 것은 불가능함. (완료된 타일 재선택 금지)
- 폭탄이 활성화되면 랜덤 배치가 끝날 때까지 "제한 시간은 일시 정지"되며, 유저는 상호작용을 할 수 없음.
```

### 5. 필드 & 타일 규격

- **타일 사이즈: 6 × 6**, **타일 간 간격: 1**
- 타일 배치는 난이도에 따라 다르게 배치된다.

| 난이도 | 타일 수 | 배치 예시 |
|---|---|---|
| 1 | **9** | 3×3 기본 배치 |
| 2~3 | **15** | |
| 4~5 | **25** | |

- 타일 상태별 색상 변화: **기본 / 호버 / 오브젝트 선택 시 / 폭탄 선택 시 / 완료**

### 6. 오브젝트

- **타일과 오브젝트는 피봇이 같다. (0, 0, 0)**
- 한 번의 상호작용에 **하나의 타일만 활성화** 가능. (최대 2개의 타일만 활성화된다)
- 판정 결과:
  - **동일한 오브젝트** → 오브젝트 제거 & 타일 색상 변경 (**파란색 → 녹색**)
  - **상이한 오브젝트** → 오브젝트 제거 & 타일 색상 변경 (**파란색 → 검정색**)
  - 위 과정 중에도 **새로운 오브젝트를 활성화하는 것이 가능**하다.
- **폭탄:** 활성화될 시 레벨에 제거되지 않은 **오브젝트의 위치가 변경**된다.

### 7. 상호작용 규격 (VR)

- 타일의 **콜리전 영역(6×6)** 에 접근하면 **타일의 바닥 색상을 변경하여 호버 표시**.
- **트리거로 상호작용**한다.
- 상호작용 시 **진동(햅틱)**.

### 8. 데이터 테이블

```
[PUZ 메인 테이블]
  - 퍼즐 ID / 퍼즐의 난이도 / 난이도별 제한시간 / 난이도별 라운드 개수 / 난이도에 속한 퍼즐 ID

[NPUZ_06_FieldData]  (필드 데이터 테이블)
  Index
  iObjectGroupID   : NPUZ_06_ObjectData의 iObjectGroupID를 참조.
                     동일한 GroupID를 공유하는 오브젝트를 불러옴
  sTileArrayX      : 필드의 X열을 지정          (예: 3)
  sTileArrayY      : 필드의 Y열을 지정          (예: 3)
  iBombTile        : 각 라운드에 등장하는 폭탄의 수  (예: 1)
  iObjectTile      : (sTileArrayX × sTileArrayY) - iBombTile 의 값.
                     ※ 반드시 짝수여야 함        (예: 8)

[NPUZ_06_ObjectData]  (오브젝트 데이터 테이블)
  오브젝트 ID
  타입 (일반 / 함정)
  챕터 (1 / 2 / 3 / 4)
  퍼즐 오브젝트 그룹 (오브젝트 그룹 ID)
  스태틱 메쉬 경로
  레벨 사이즈
```

- **배치되는 Bomb와 Object의 위치는 랜덤으로 변환된다.**
- 오브젝트 그룹 ID로 동일 그룹의 오브젝트를 데이터 테이블에서 호출 → X열/Y열 정렬에 따라 폭탄/오브젝트 배치.

### 9. 구현 요구사항

1. 필드 생성 알고리즘:
   ```
   total   = sTileArrayX * sTileArrayY
   objects = total - iBombTile          // 반드시 짝수 (assert)
   pairs   = objects / 2
   → iObjectGroupID로 오브젝트 풀에서 pairs 종류를 뽑고 각 2개씩 생성
   → 폭탄 iBombTile 개 추가
   → 전체를 랜덤 셔플하여 타일에 배치
   ```
   `iObjectTile`이 홀수가 되는 테이블 값은 **데이터 검증 단계에서 에러**로 처리한다.
2. 타일 상태 머신: `HIDDEN → REVEALED → (MATCHED | HIDDEN)`, 별도로 `BOMB_REVEALED`. `MATCHED`와 폭탄 타일은 **재선택 불가**.
3. **폭탄 셔플**: 폭탄 발견 시 `MATCHED`가 아닌 모든 타일의 오브젝트 배정을 랜덤 재배치한다. 이때 **타이머 일시정지 + 입력 잠금**을 걸고, 셔플 연출 종료 후 해제한다. 폭탄 타일 자신은 비활성화된다.
4. **동시 활성화 방지**: 활성 슬롯을 최대 2로 제한하고, 입력은 큐로 직렬 처리한다. 두 개가 이미 열린 상태에서의 세 번째 입력은 (판정 연출 중이라면) 판정을 즉시 완료시키고 새 선택으로 넘어가도록 처리한다 — "1), 2)의 과정에서 새로운 오브젝트를 활성화하는 것도 가능"하다는 명세를 만족시켜야 한다.
5. **리셋 비활성화**: 리셋 버튼 입력은 무시(no-op)하되 UI상 존재는 유지한다.
6. 클리어 판정: `폭탄이 아닌 모든 타일이 MATCHED` → 클리어. 남은 타일이 폭탄뿐인 상황도 클리어로 처리한다.
7. 테스트: 홀수 iObjectTile 데이터 거부 / 폭탄 셔플 중 입력·타이머 잠금 / 완료 타일 재선택 차단 / 판정 연출 중 세 번째 타일 선택 / 마지막 남은 타일이 폭탄일 때 클리어.

## 모바일 조작 규격 (§7 VR 상호작용 규격 대체)

> 이 퍼즐은 드래그가 없고 **탭 하나**로 끝난다.
> 구현: `CardMatch_Session.revealTile()`, `CardMatch_Board.reveal()`

### M1. 단일 터치 전용

- 포탈을 **동시에** 활성화하는 것은 불가능하다 (§4). 단일 터치이므로 입력은 자연히 직렬 처리된다.
- 같은 프레임에 여러 손가락이 닿아도 하나씩 순서대로 처리된다.

### M2. 호버 대체

- VR의 콜리전 호버(§7)는 모바일에 없다. 대신 **누르는 순간 눌림 상태(pressed)** 를 표시한다.
- 손가락이 타일을 가리므로, 활성화된 오브젝트는 타일보다 **위로 크게** 띄워 보여 준다.

### M3. 타일 상태별 색상 (§5)

기본 / 눌림 / 오브젝트 선택 / 폭탄 선택 / 완료 5가지를 구분한다.

- 짝이 맞음: 파란색 → **녹색** (§6)
- 짝이 틀림: 파란색 → **검정색** (§6)

### M4. 판정 연출 중 입력

- 짝이 틀려 되돌아가는 연출 중에도 **새 타일을 누를 수 있다** (§4 / §9.4).
- 그러면 직전 판정을 **즉시 마무리**하고 새 선택으로 넘어간다.

### M5. 폭탄

- 폭탄이 나오면 **입력이 잠기고 제한 시간이 멈춘다** (§4).
- 셔플 연출이 끝나면 둘 다 해제된다.
- 잠금 중 터치는 사유(`LOCKED_BY_BOMB`)와 함께 거절된다.

### M6. 리셋 버튼

- 버튼은 UI에 남기되 **눌러도 아무 일도 일어나지 않는다** (§1 / §9.5).
- `RESET_IGNORED` 이벤트만 발행되므로, 필요하면 "폭탄을 찾으세요" 같은 힌트를 띄울 수 있다.
