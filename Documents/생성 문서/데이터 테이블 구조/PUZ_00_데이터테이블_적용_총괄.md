## 2. 공통 인덱스 규칙

전 퍼즐 CSV 가 같은 10자리 인덱스를 쓴다. NPUZ_02 에만 있는 `#PUZCategory` /
`#Difficulty` / `#Order` 컬럼으로 이 해석을 교차 검증했다.

```
8 0 0 0 1 0 1 0 0 1
└┬┘ │ └┬┘ └┬┘ └─┬─┘
 80 0  01  01   001
 │   │  │   │    └ 순서 (난이도 안에서의 진행 순번)
 │   │  │   └────── 난이도 01~06
 │   │  └────────── 퍼즐 종류 01 레이저 … 08 스위치
 │   └───────────── 미사용
 └───────────────── 퍼즐 데이터 구분자
```

오브젝트 ID 는 퍼즐마다 규칙이 다르지만 앞 두 자리가 퍼즐을 가리킨다

## 3. 변환 파이프라인

CSV 는 런타임에 읽을 수 없으므로(Horizon Worlds 스크립트는 파일 I/O 가 없다)
빌드 시점에 TypeScript 로 변환한다.

```bash
cd Documents/Tools
python build_fielddata.py              # 8개 퍼즐 전부 재생성
python build_fielddata.py laser flow   # 일부만
```

| 도구 | 역할 |
|---|---|
| `dt_common.py` | CSV 로더 (인코딩 자동 판별, 인덱스 파싱, 좌표 컬럼 수집) |
| `build_fielddata.py` | 8개 변환기를 한 번에 돌리는 진입점 |
| `build_<퍼즐>.py` | 퍼즐별 변환기. 변환하면서 **기획 규칙 위반을 함께 검사**한다 |
| `rushhour_minmoves.json` | 러시아워 최소 이동 수 (솔버로 미리 계산) |
| `switch_minpresses.py` / `.json` | 스위치 최소 누름 수 (GF(2) 로 계산) |

생성물은 `<Puzzle>_FieldData.ts` 8개다. **자동 생성 파일이므로 직접 고치지 않는다.**
좌표 격자가 큰 퍼즐은 레벨 한 판을 문자열 한 줄로 인코딩해 파일을 작게 유지했다
(전체 8개 합쳐 약 122KB).

## 6. 로직을 고쳐야 했던 지점

데이터를 붙이면서 **구현이 기획 데이터를 담지 못하던 곳**을 고쳤다. 데이터 연결만으로 끝난
퍼즐은 PUZ_07 하나뿐이다.

| 퍼즐 | 고친 내용 |
|---|---|
| PUZ_01 | 인벤토리 상한 5→10, 힌트 탐색에 예산 부여 (안 하면 클라이언트가 1~2초 멈춘다) |
| PUZ_02 | 도착 판정을 "앞머리가 포인트 칸에 맞닿음"으로 일반화, 필드 안쪽 포인트 칸을 점유 불가로 처리, §6 검증을 생성기 전용으로 분리 |
| PUZ_03 | **클리어 판정 버그 수정** — 같은 색이 두 케이스에 있으면 미완성으로 보던 제약 제거 (안 고치면 13판이 영원히 클리어 불가) |
| PUZ_04 | 검증 봇 반응 시간을 레벨 타이밍에 맞춰 스케일링 (안 하면 난이도 4 레벨이 하나도 생성되지 않는다) |
| PUZ_05 | 없음 (데이터 연결만) |
| PUZ_06 | 난이도별 `fieldIndexes` 를 테이블에서 계산하도록 변경 + 기존에 깨져 있던 테스트 1건 수정 |
| PUZ_07 | 없음 (데이터 연결만) |
| PUZ_08 | 초기 배치를 직접 로드하는 경로 추가 (`initialRows`). 기존 역셔플 경로는 그대로 유지 |
| 공통 | 한 퀘스트 안에서 같은 판이 다시 나오지 않도록 세션에 사용 이력 추가 (8개 퍼즐 전부) |

## 7. 남은 과제

1. **PUZ_05 경로를 색이 아니라 쌍 ID 로 관리** — 지금은 한 판에 같은 색 쌍이 둘 있으면
   변환기가 색을 바꿔서 우회한다. 120판 중 1판만 해당해 후순위로 뒀다.
2. **PUZ_01 솔버 가지치기** — 인벤토리 7~9개 판에서 완전 탐색이 폭발한다.
   수신체 역추적이나 색 레이어별 분리 탐색을 넣으면 미확정 13판을 확정할 수 있다.
3. **오브젝트 메쉬 경로 미정** — PUZ_04(2행)와 PUZ_05(17행)의 메쉬 경로가 `FREE` 다.
   리소스가 정해지면 CSV 만 갱신하면 된다.
