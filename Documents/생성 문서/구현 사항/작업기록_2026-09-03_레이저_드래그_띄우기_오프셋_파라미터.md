# 작업기록 2026-09-03 — 레이저 드래그 띄우기 오프셋을 에디터 파라미터로

> 지시: "터치 후 드래그 시 드래그중인 손가락 위치보다 조금 위의 오프셋을 줘서 내가
> 드래그 하고 있는 오브젝트가 더 잘보이게 처리해줬으면 하는데, 레이저 퍼즐만 해당하게
> 수정하고 오프셋은 LaserCoreApi에서 조정할수 있게 수치 파라미터로 빼줘"
> 관련 문서: `작업기록_2026-09-02_드래그_조작_시각_피드백.md` (띄우기 도입 경위)

## 1. 무엇이 어떻게 바뀌었나

집은 조각을 손가락 위로 띄우는 동작 자체는 이미 레이저 전용으로 들어 있었다
(`PuzzleBoardLayoutSpec.liftGrabbedPiece` — 레이저만 켠다). 이번에 **띄우는 거리**를
패널 상수에서 **레이저 CoreAPI 의 에디터 prop** 으로 뺐다.

```
Laser_CoreAPI.dragLiftCells (기본 0.9)
   └→ PuzzleBoardLayoutSpec.grabLiftCellRatio
       └→ PuzzleBoardView.grabLiftCellRatio
           └→ PuzzleBoardUIPanel.grabLiftPixels() = 칸 한 변 × 배수
```

- 단위는 **격자 칸 한 변의 배수**다. 0.9 면 거의 한 칸 위에 뜬다. 0 이면 띄우지 않는다.
- 음수는 0 으로, 못 쓰는 값(NaN)은 기본값(0.9)으로 다듬는다
  (`PuzzleBoardUI_Definitions.resolveGrabLiftRatio`).
- 예전 패널의 상·하한 클램프(기준 캔버스 64~150px)는 **버렸다.** 배수가 에디터에서
  조정하는 파라미터가 되면서, 클램프가 조정값을 조용히 무시하는 함정이 되기 때문이다.
  레이저 격자(7×7)의 기본값 기준으로는 클램프에 걸리지 않던 구간이라 화면 변화도 없다.

## 2. 에디터에서 조정하는 법

`Laser_CoreAPI` 컴포넌트의 **dragLiftCells** 값을 바꾼다.

| 값 | 화면 |
|---|---|
| 0 | 손가락 바로 밑 (안 띄움) |
| 0.9 (기본) | 손가락 위로 거의 한 칸 |
| 1.5 | 한 칸 반 — 손가락이 커서 조각이 계속 가려질 때 |

다른 퍼즐은 `liftGrabbedPiece` 를 켜지 않으므로 이 값과 무관하다 (탭·밀기 퍼즐이
띄우면 조준을 흐린다는 피드백으로 꺼 둔 상태 그대로다).

## 3. 바뀐 파일

| 파일 | 내용 |
|---|---|
| `Laser_CoreAPI.ts` | `dragLiftCells` prop 추가, 프레젠터 규격에 `grabLiftCellRatio` 전달 |
| `PuzzleBoardUI_Definitions.ts` | 규격·뷰에 `grabLiftCellRatio` 추가, 기본값 상수와 다듬기 함수 |
| `PuzzleBoardUI_Panel.ts` | 상수 3개 제거, 배수를 뷰에서 받아 `칸 한 변 × 배수` 로 환산 |
| `PuzzleBoardUI_Tests.ts` | 기본값·지정값·0·음수·NaN 다듬기 검증 5건 추가 |
