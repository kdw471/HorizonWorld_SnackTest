# 버그수정 2026-09-02 — 끌고 가서 손을 떼도 오브젝트가 놓이지 않는다

> 지시: `worker/NextJob.md` 2번 — "여전히 꾹 눌러서 드래그로 이동하는 오브젝트들에 대해서
> 터치를 떼는 경우 오브젝트가 놓아지는 판정이 되질 않아, 그런식으로 작동하게 수정해줘"
> 관련 문서: `작업기록_2026-09-02_드래그_조작_시각_피드백.md` (같은 계통의 앞선 수정)

## 1. 증상

오브젝트를 꾹 눌러 집고 다른 칸으로 끌고 간 뒤 손을 떼면, **그 칸에 놓이지 않고 원래
자리로 되돌아간다.** 드래그를 쓰는 네 퍼즐(레이저·러시아워·정렬·연결)에서 모두 나타났다.

집는 것과 따라오는 것은 정상이었다. **마지막 한 걸음, "여기 놓았다" 만 빠졌다.**

## 2. 원인 — 뗄 때 도착하는 `onExit` 이 드랍 지점을 지웠다

`Pressable` 은 손가락이 떨어질 때 **`onExit` 을 `onRelease` 보다 먼저 보내는 경우가 있다.**
프레젠터는 그 exit 을 "칸에서 빠져나갔다" 로 받아 `_hoverCell` 을 판 밖으로 만들고,
곧이어 도착한 release 는 이미 비어 있는 hover 를 보고 **"판 밖에 놓았다"** 로 판정했다.

```
손가락 B 위에서 뗌
   onExit(B)     -> _hoverCell = 판 밖   ← 여기서 드랍 지점이 지워졌다
   onRelease     -> onCellUp(판 밖)      ← 세션은 "밖에 놓았다" 로 받는다
                                            레이저는 인벤토리로 회수, 러시아워는 원위치
```

여기에 두 번째 경로가 겹칠 수 있었다. 칸의 release 가 부모(격자를 담은 상자)로 올라가면
그 상자의 처리기가 `pointerLeaveBoard()` 를 불러 **"판을 벗어났다" 로 단정**했다.
칸 위에서 뗐는데도 같은 결과가 된다.

## 3. 고친 방법

### 3.1 마지막으로 올라가 있던 "진짜 칸" 을 따로 기억한다

hover 와 별개로 `_lastInsideCell` 을 둔다. 스쳐 가는 `onExit` 으로는 지워지지 않고,
**판을 진짜로 벗어났을 때만** 지워진다. 뗄 때 hover 가 비어 있으면 이 값에 놓는다.

```
exit(B) → release          hover=밖, 마지막 진짜 칸=B   ->  B 에 놓는다      ✅
판 밖으로 나감 → release    pointerLeaveBoard() 가 둘 다 지웠다  ->  밖에 놓는다 ✅
```

둘을 가르는 것은 `pointerLeaveBoard()` 다. 이것은 **격자 밖 배경이 보내는 명시적인 신호**라
칸끼리 오갈 때 스쳐 가는 exit 과 뒤섞이지 않는다.

### 3.2 격자를 담은 상자는 "밖" 으로 단정하지 않는다

배경 처리기를 둘로 갈랐다.

| 어디서 뗐나 | 무엇을 하나 | 왜 |
|---|---|---|
| 격자를 담은 상자 (`onBoardAreaRelease`) | `pointerUp()` 만 | 칸 위에서 뗀 것이 부모로 올라온 것일 수 있다. 밖으로 단정하면 3.1 이 무의미해진다 |
| 보조 레이아웃 (`onAuxAreaRelease`) | `pointerLeaveBoard()` + `pointerUp()` | 여기는 판이 아닌 것이 **확실하다.** 트레이에 도로 떨어뜨린 크리스탈은 인벤토리로 돌아가야 한다 (PUZ_01 §3 3.3) |

격자와 상자 사이의 얇은 여백에서 떼면 마지막으로 지나온 칸에 놓인다. **아무 데도 놓이지
않는 것보다 낫다** — 원래 요구가 "떼면 놓인다" 이기 때문이다.

## 4. 곁가지로 함께 고쳐진 것

누른 칸에서 그대로 떼는 **탭**도 같은 문제를 안고 있었다. exit 이 먼저 오면 뗀 칸이 판 밖이
되어 `onCellTap` 이 나가지 않았다. 이제는 탭도 확실히 확정된다 (스위치 M2, 슬라이드, 카드).

트레이에서 집어 판으로 끌어다 놓는 경로도 같은 규칙을 탄다.

## 6. 검증

새로 넣은 검증은 넷이다.

| 검증 | 기대 |
|---|---|
| 칸 A 에서 집어 B 로 끌고, **떼기 직전 exit(B)** 이 온 뒤 뗌 | `onCellUp(B)` — B 에 놓인다 |
| 누른 칸에서 exit 이 온 뒤 뗌 | `onCellUp(A)` + `onCellTap(A)` — 탭으로 확정 |
| 판을 벗어난 뒤(`pointerLeaveBoard`) 뗌 | `onCellUp(판 밖)` — 밖에 놓은 것 |
| 트레이에서 집어 B 로 끌고, 떼기 직전 exit(B) 뒤 뗌 | `onCellUp(B)` |

기존 검증 하나(`입력 - 칸 밖에서 떼면 OUTSIDE`)는 **버그 쪽 동작을 굳히고 있어서** 고쳤다.
`pointerExit()` 하나만으로 "판 밖" 을 단정하던 것을, 판을 벗어났다는 명시적 신호
(`pointerLeaveBoard()`)로 바꿨다.

## 7. 인월드에서 확인할 것

코드로는 여기까지다. 실기에서 다음 두 가지를 본다.

1. 네 퍼즐에서 **끌고 가서 뗀 칸에 그대로 놓이는지**
2. 트레이 쪽이나 판 밖으로 끌어내 떼면 **원래대로 회수되는지** (레이저 크리스탈)

2번이 안 되면 `onAuxAreaRelease` 가 안 불리는 것이므로, 보조 레이아웃 배경의
`Pressable` 이 release 를 받는지부터 본다.
