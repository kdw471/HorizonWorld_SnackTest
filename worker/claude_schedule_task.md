# 러시 아워 모바일 개편 및 연속 퍼즐 구현 스케줄 지시서

## 작업 Github 주소: https://github.com/kdw471/HorizonWorld_SnackTest

## 1. 첫 번째 스케줄 작업 (TASK-01)
- **작업 예약 시간:** 오늘 08:30 PM
- **작업 개요:** 러시 아워 모바일 인터랙션 수정 및 미구현 퍼즐 순차 레이어 구현

### [Step 1] 러시 아워 모바일 사양 적용
1. `Prompts/Rush_Hour_Mobile_Specification.md` 문서를 참고합니다.
2. 현재 진행 중인 러시 아워 구현을 모바일 기기에 맞는 터치/드래그 인터랙션 방식으로 수정합니다.
3. 모바일 레이아웃 및 조작감에 맞춰 관련 로직 및 UI 코드를 업데이트합니다.

### [Step 2] 미구현 퍼즐 순차적 신규 레이어 추가
1. `Prompts/` 폴더 하위에 존재하는 미구현 퍼즐 기획 문서들을 확인합니다.
2. 기획서를 **한 번에 하나씩 가져와서** 현재 프로젝트에 **신규 레이어로 추가**합니다.
3. 러시 아워와 동일하게 모바일 기기 인터랙션에 맞춰 로직을 구현합니다.
4. 구현에 맞춰 `Prompts/` 하위의 해당 `.md` 사양 문서도 변경된 모바일 인터랙션에 맞게 업데이트합니다.

## 2. 두 번째 스케줄 작업 (TASK-02)
- **작업 예약 시간:** 오늘 09:30 PM부터 매 1시간마다 반복
- **작업 개요:** 프로세스 수행 상태 및 토큰 잔여량 체크 후 작업 자동 이어가기

### [상태 점검 및 실행 규칙]
1. **작업 수행 여부 체크:**
   - 첫 번째 스케줄 작업(또는 이어서 진행 중인 퍼즐 작업)이 현재 실행 중인지 확인합니다.
   - 실행 중이라면 아무 작업도 하지 않고 다음 1시간 주기까지 대기합니다.
2. **토큰 및 작업 재개 체크 (작업 미수행 시):**
   - 현재 실행 중인 작업이 없고 **토큰이 남아있다면**, Step 2의 미구현 퍼즐 작업을 계속해서 이어서 수행합니다.
   - **토큰이 소진된 경우**, 토큰이 리셋될 때까지 대기 상태를 유지합니다.

## 3. 예외 및 로깅 규칙
- 작업 상태는 프로젝트 내 로그 파일(`logs/task_schedule_status.json`)에 기록하여 다음 체크 주기 시 이전 작업 이력을 확인할 수 있도록 합니다.
- 작업 완료 시 각 단계별 실행 결과를 요약하여 보고합니다.
